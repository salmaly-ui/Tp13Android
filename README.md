
Application Android qui permet de suivre votre position GPS et de l'enregistrer sur un serveur.

## Prérequis

- Android Studio (dernière version)
- Téléphone Android (Android 7.0+)
- PC avec XAMPP/WAMP
- Les deux appareils sur le même réseau WiFi
